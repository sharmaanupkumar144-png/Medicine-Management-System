# 💊 Medicine Management System

A Python-based Medicine Management System built to simplify medicine inventory management and pharmacy operations. The project uses SQLite for database storage and provides a menu-driven command-line interface.

## 📌 About the Project

The Medicine Management System is designed to organize medicine records, manage inventory, process sales, and generate reports. It demonstrates practical applications of Python programming and database management.

## ✨ Features

- Add and manage medicine records
- Display and search medicines
- Update and delete medicine information
- Manage medicine inventory and stock
- Record medicine sales
- Handle sales cancellations
- Generate inventory and sales reports
- Store data using an SQLite database

## 🛠️ Technologies Used

- **Language:** Python
- **Database:** SQLite
- **Interface:** Command-Line Interface (CLI)

## 📂 Project Modules

- `main.py` — Main application and menu
- `medicine.py` — Medicine record management
- `sales.py` — Sales-related operations
- `reports.py` — Inventory and sales reports
- `database.py` — Database setup and operations

## 🚀 Getting Started

### Prerequisites

- Python 3 installed on your system

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/sharmaanupkumar144-png/Medicine-Management-System.git
```

**2. Navigate to the project directory**

```bash
cd Medicine-Management-System
```

**3. Run the application**

```bash
python main.py
```

Follow the menu displayed in the terminal to use the available features.

The objective of this project is to apply Python programming and database concepts to develop a simple medicine inventory management application.
